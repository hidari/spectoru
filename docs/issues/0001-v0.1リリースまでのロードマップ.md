# [Umbrella] v0.1 リリースまでのロードマップ

`docs/planning/方向性.md` で定義した v0.1 スコープを実装しきるまでの親 issue。
個別の作業はサブ issue に切り出し、ここでは全体の進捗と依存関係のみを管理する。

## 完成の定義

`spectoru build --config spec-site.toml --out dist/` が、Rust と Vitest の
テストを含むリポジトリに対して単一 HTML の仕様サイトを生成する。
`extract` / `render` / `lint` の各サブコマンドが動作し、`--strict` が CI の
品質ゲートとして使える。

## アーキテクチャ方針

ヘキサゴナル + library-contract パターン。

| 層 | 役割 | 外部 crate |
|---|---|---|
| `core/` | ドメイン値型と純関数 | 禁止 |
| `ports/` | 境界を定義する trait のみ | 禁止 |
| `adapters/` | 外部 crate の具象実装 | ここだけ許可 |
| `app/` | ポートを合成するユースケース | 禁止（trait 経由） |

この境界は `crates/spectoru/tests/architecture.rs` がソース走査で機械的に検証する。
各 adapter は対応する `tests/contract_*.rs` を持ち、「ライブラリを差し替えても
守られるべき契約」を固定する。
