# [Phase 4] I/O アダプタ群の実装

親: [0001](./0001-v0.1リリースまでのロードマップ.md)
依存: [0002](./0002-中間表現のproject層導入とport拡充.md)

## 目的

`ports/` に定義済みの I/O 系ポートに対して、外部 crate を使う具象実装を与える。
パーサ（0004）と application 層（0005）が土台として必要とする。

## 実装対象

| ポート | adapter | 使用 crate |
|---|---|---|
| `TomlCodec` | `toml_config_codec` | `toml` |
| `FileWalker` | `ignore_file_walker` | `ignore` |
| `FileWriter` | `fs_file_writer` | std のみ |
| `GitProvider` | `command_git_provider` | std のみ（`git rev-parse HEAD`） |
| `Clock` | `system_clock` | `time`（暦日への変換のみ） |

## 設計メモ

- **`FileWalker`**: `.gitignore` を尊重し、`target/` と `node_modules/` を除外する。
  返す `DiscoveredFile.relative` は root からの相対パスで、そのまま IR の `file` に
  入る形にする。**結果は必ずパス順にソートする**（同じ入力から同じフラグメントが
  出ることが JSON フラグメントの前提）
- **`GitProvider`**: 外部プロセス起動になるため、引数は固定文字列のみとし、
  ユーザー入力を渡さない。git 不在・リポジトリ外・detached など失敗はすべて
  `None` に畳む（`Result` ではないのは「取得不能」がエラーではないため）
- **`Clock`**: ISO 8601 UTC 秒精度。`chrono` はメンテナンス面と依存の重さから
  避け、`jiff` か `time` を候補にする。std の `SystemTime` から自前で
  日付計算する案もあるが、閏年・閏秒の扱いを自作するのは割に合わない
- **`FileWriter`**: 親ディレクトリを再帰的に作成する

### 決定: 対象ディレクトリは `-C` ではなく `current_dir` で渡す

`git -C <path> rev-parse HEAD` だと、パスが `-` で始まる場合に git がそれを
オプションとして解釈しうる。`Command::current_dir` を使えば引数そのものが
消えるため、この経路が塞がる。シェルを介さないので引数分割やグロブ展開も起きない。

### 決定: グローバル gitignore は読まない

`~/.config/git/ignore` を参照すると、同じソースツリーからでも実行環境によって
抽出結果が変わってしまう。リポジトリ内の `.gitignore` と `.git/info/exclude` は
尊重するが、利用者ごとの設定は読まない。

### 決定: 時刻フォーマットは自前で組み立てる

`time` crate は使うが、well-known な RFC 3339 フォーマッタは値によって小数秒を
出し分ける。「常に秒精度」という契約を守るには `format!` で組む方が確実になる。
crate に任せるのはエポック秒から暦日への変換だけにとどめる。

### 決定: 設定として意味をなさない値は明示的に弾く

型としては通るが動作が無意味になる設定（`[[sources]]` が空、source の `paths` が
空、`max_depth = 0`）はエラーにする。いずれも「書いたのに何も起きない」という
最も原因を追いにくい失敗につながるため。同じ理由で DTO には
`deny_unknown_fields` を付け、キー名の打ち間違いを黙って無視しない。

## テスト

各 adapter に `tests/contract_*.rs` を追加する。契約テストは「ライブラリを
差し替えても守られるべき性質」のみを検証し、実装の内部構造には触れない。

- `TomlCodec`: 最小構成 / 全項目 / `max_depth` 省略時のデフォルト / 未知キー /
  不正な `kind` / 壊れた TOML がそれぞれ期待どおりの値かエラーになる
- `FileWalker`: `.gitignore` 除外、`target` / `node_modules` 除外、拡張子
  フィルタ、**列挙順が決定的**、存在しない root
- `Clock`: 戻り値が `Z` 終端の ISO 8601 形式である（値そのものは検証しない）
- `GitProvider`: git リポジトリ外で `None` を返す
- `FileWriter`: 未作成の親ディレクトリに書ける、既存ファイルを上書きする

## 併せて対応（ボーイスカウトルール）

`TomlCodec::decode_config` が `source: &str` しか受け取らないのに、
返しうる `SpectoruError::TomlParse` は `path` を要求していた。設定ファイルの
誤りは利用者が最も頻繁に出会うエラーであり、どのファイルが悪いのか伝えられ
なければ意味がない。パーサ系ポートと同じく `(path, source)` を受け取る形に揃えた。

`JsonCodec` にも同種の課題が残っている。`render --fragments a.json b.json` で
デコードに失敗したとき、`JsonDecode { message }` だけではどのフラグメントが
壊れているのか分からない。ただし JSON codec はファイル専用ではなく汎用の
文字列 codec でもあるため、パスの付与は application 層の責務として 0005 で扱う。

依存 crate が増えたが、追加のライセンス許可は不要だった（すべて MIT /
Apache-2.0 で充足）。
