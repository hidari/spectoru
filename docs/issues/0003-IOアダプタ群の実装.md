# [Phase 4] I/O アダプタ群の実装

親: [0001](./0001-v0.1リリースまでのロードマップ.md)
依存: [0002](./0002-中間表現のproject層導入とport拡充.md)

## 目的

`ports/` に定義済みの I/O 系ポートに対して、外部 crate を使う具象実装を与える。
パーサ（0004）と application 層（0005）が土台として必要とする。

## 実装対象

| ポート | adapter | 使用 crate |
|---|---|---|
| `TomlCodec` | `toml_config_codec` | `toml` |
| `FileWalker` | `ignore_file_walker` | `ignore` |
| `FileWriter` | `fs_file_writer` | std のみ |
| `GitProvider` | `command_git_provider` | std のみ（`git rev-parse HEAD`） |
| `Clock` | `system_clock` | 時刻フォーマット用に 1 crate |

## 設計メモ

- **`FileWalker`**: `.gitignore` を尊重し、`target/` と `node_modules/` を除外する。
  返す `DiscoveredFile.relative` は root からの相対パスで、そのまま IR の `file` に
  入る形にする。**結果は必ずパス順にソートする**（同じ入力から同じフラグメントが
  出ることが JSON フラグメントの前提）
- **`GitProvider`**: 外部プロセス起動になるため、引数は固定文字列のみとし、
  ユーザー入力を渡さない。git 不在・リポジトリ外・detached など失敗はすべて
  `None` に畳む（`Result` ではないのは「取得不能」がエラーではないため）
- **`Clock`**: ISO 8601 UTC 秒精度。`chrono` はメンテナンス面と依存の重さから
  避け、`jiff` か `time` を候補にする。std の `SystemTime` から自前で
  日付計算する案もあるが、閏年・閏秒の扱いを自作するのは割に合わない
- **`FileWriter`**: 親ディレクトリを再帰的に作成する。出力パスがシンボリック
  リンク経由で意図しない場所を指さないよう、書き込み先の検証方針を決める

## テスト

各 adapter に `tests/contract_*.rs` を追加する。契約テストは「ライブラリを
差し替えても守られるべき性質」のみを検証し、実装の内部構造には触れない。

- `TomlCodec`: 最小構成 / 全項目 / `max_depth` 省略時のデフォルト / 未知キー /
  不正な `kind` / 壊れた TOML がそれぞれ期待どおりの値かエラーになる
- `FileWalker`: `.gitignore` 除外、`target` / `node_modules` 除外、拡張子
  フィルタ、**列挙順が決定的**、存在しない root
- `Clock`: 戻り値が `Z` 終端の ISO 8601 形式である（値そのものは検証しない）
- `GitProvider`: git リポジトリ外で `None` を返す
- `FileWriter`: 未作成の親ディレクトリに書ける、既存ファイルを上書きする

## 併せて対応

依存 crate が一気に増えるため、`deny.toml` の `licenses.allow` を更新する。
新しいライセンスを追加する際は、なぜ許可してよいかを判断してから足す。
